# FoloRID — Open-source ESP32 Remote ID Receiver

[English](README.md) | [简体中文](README.zh_CN.md)

Open-source **Remote ID receive & parse** application for the
[FoloToy AI Passport](https://gitee.com/FoloToy/ai-passport).

See `README.zh_CN.md` for the full Chinese documentation (features, hardware,
build & flash steps, disclaimer). Protocol reference: OpenDroneID / ASTM F3411,
PeterJBurke/RID, opendroneid-core-c.

Firmware image: `build/FoloToy-AI-Passport-full.bin`, flash from offset `0x0`.
